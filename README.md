# OpenTV

A privacy-first TV and film tracker for iPhone and Android. Your library stays on your phone.

**This repository only hosts the privacy policy and terms.** The code lives here:

- **The app** (iPhone + Android, Expo / React Native): https://github.com/mahmoodbashar08/opentv-app (MPL-2.0)
- **The server** (the optional community layer, Cloudflare Workers): https://github.com/mahmoodbashar08/OpenTv-backend

Website: https://theopentv.com · Contact: info@theopentv.com

- [Privacy policy](https://mahmoodbashar08.github.io/opentv/privacy.html)
- [Terms](https://mahmoodbashar08.github.io/opentv/terms.html)

Show and film metadata and artwork are provided by TheTVDB and TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.
